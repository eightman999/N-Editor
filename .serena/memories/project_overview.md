# NavalDesignSystem (NDS) - Project Overview

## Purpose
NDS is a Python (PyQt5) desktop application designed for creating modifications (MODs) for Paradox Interactive's Hearts of Iron IV (HOI4). It provides a graphical interface for editing game script files including:

- Naval Orders of Battle (OOB) - Fleet compositions
- Ship designs and hull templates  
- Equipment (naval weapons/components)
- State files, strategic regions, country definitions

## Key Features
- **Ship Design Editor**: Create and modify ship designs with equipment slots
- **Equipment Management**: Define naval weapons, armor, engines with calculated stats
- **Hull Templates**: Manage ship hull types and their characteristics
- **Fleet Composition**: Design naval formations and task forces
- **MOD Integration**: Select and work with existing HOI4 MODs
- **Data Synchronization**: GitHub integration for team collaboration
- **Map Viewer**: Visual province/state editing capabilities

## Target Users
- HOI4 MOD creators and developers
- Naval warfare enthusiasts creating custom ship designs
- Teams collaborating on large-scale HOI4 modifications
