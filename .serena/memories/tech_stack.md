# Technology Stack

## Core Technologies
- **Language**: Python 3.12+
- **GUI Framework**: PyQt5 (version ~5.15.11)
- **Package Management**: Poetry (pyproject.toml)

## Key Dependencies
- **PLY (Python Lex-Yacc)**: Custom parsers for HOI4 script formats
- **NumPy**: Numerical computations (~2.2.5)
- **Pillow**: Image processing (~11.2.1)
- **OpenCV**: Advanced image operations (~4.11.0.86)
- **PyYAML**: Configuration file handling (~6.0.2)
- **Requests**: HTTP requests for web features (~2.32.3)
- **BeautifulSoup4**: Web scraping capabilities (^4.13.4)

## Specialized Libraries
- **miyabi256**: Custom utilities (~0.1.2)
- **googletrans**: Translation services (~4.0.0-rc1)
- **hoi4-modding-tools**: Custom HOI4 modding utilities (Git dependency)

## Development Tools
- **psutil**: System monitoring (~7.0.0)
- **lxml**: XML processing (==6.0.0)

## Runtime Environment
- Supports Windows, macOS (Darwin), and Linux
- Platform-specific Qt plugin handling
- Virtual environment with Poetry dependency management
